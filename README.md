# kiddie-game

**Nina's Toverbakkerij** — a magic-bakery game in Dutch for a 4-year-old, built
in SwiftUI for iPad.

**Where it is:** the first room is built. [app/](app/) holds **De Keuken** — one
full round (ingredients, stir, pour, bake), six toys, and 86 Dutch voice lines.
Start at [app/README.md](app/README.md).

**Next:** test it with Nina, then the decorating room.

See [GAMEPLAY.md](GAMEPLAY.md) for the storyline and gameplay,
[CONCEPT.md](CONCEPT.md) for the design, [POC.md](POC.md) for why the art
direction is what it is, and [CLAUDE.md](CLAUDE.md) for the working brief.
